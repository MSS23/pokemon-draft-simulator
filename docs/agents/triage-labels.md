# Triage labels

These labels exist on the GitHub repository. Apply exactly one triage label
to an open issue.

| Label | Meaning |
|---|---|
| `needs-triage` | New; a maintainer has not evaluated it yet |
| `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | Fully specified; an agent can implement it without questions |
| `ready-for-human` | Needs human judgement, credentials or dashboard access |
| `wontfix` | Will not be worked on |

The GitHub defaults (`bug`, `enhancement`, `documentation`, ...) describe the
kind of issue and can be combined with a triage label.
