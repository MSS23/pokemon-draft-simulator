# Domain docs

This repository has a single domain context.

- [`GLOSSARY.md`](../../GLOSSARY.md) at the repo root defines the terms used in
  code, UI and issues. Use those words; add a term there when you introduce one.
- [`docs/adr/`](../adr/) holds architecture decision records, one file per
  decision, numbered `NNNN-short-title.md`. Add one when a change fixes a
  long-lived constraint (auth model, where state is authoritative, schema
  process).
