# Review — 2026-10-10

## What the project is for

A free, real-time draft-league platform for competitive Pokémon players
(primarily Pokémon Champions / VGC doubles communities). A host creates a
snake, tiered or auction draft, shares a room code, players join with an
account or as guests, and the draft runs live with server-enforced turns,
budgets and timers. Completed drafts can become a league season (schedule,
KO-based standings, trades, waivers, playoffs) or a tournament.

State at review time: mature codebase. Baseline was green before any change —
`tsc` 0 errors, ESLint clean, 440/440 Vitest tests, `next build` OK.
Format data is current: Champions **M-C** (231 species, Sep 8 – Dec 1 2026) is
the default; the README's "VGC 2024 Reg H" framing was what was stale.

## Live check (draftpokemon.com)

`pokemon-draft-simulator.vercel.app` 308-redirects to `draftpokemon.com`.
All key routes return 200 (`/`, `/create-draft`, `/join-draft`, `/about`,
`/lobby`, `/sign-in`, `/privacy`, `/og-image`, `/api/health` → healthy,
DB up). Findings:

1. **Broken sitemap + robots.** Every `<loc>` in `/sitemap.xml` and the
   `Sitemap:` line in `/robots.txt` contained a newline
   (`https://draftpokemon.com\n/sign-in`) — the `NEXT_PUBLIC_SITE_URL` env
   value in Vercel ends with `\n`. Search engines see invalid URLs.
2. **Every page canonicalised to the homepage.** The root layout set
   `alternates.canonical: "https://draftpokemon.com"`, which all routes
   inherit — telling Google that `/create-draft`, `/about`, leagues etc. are
   duplicates of `/`.
3. **Sitemap listed `/draft/*/results` URLs that robots.txt disallows.**
4. **Doubled title suffix** on `/about`, `/sign-in`, `/sign-up`, `/privacy`,
   `/terms` ("Sign in — Pokémon Champions Draft League | Pokémon Champions
   Draft League").
5. **Stale copy** — homepage, `/create-draft` meta description, product tour
   and admin page still pitched "VGC Reg H" as the headline format.
6. `/draft/<any-id>` returns 200 with "Live" OG metadata even for drafts that
   don't exist (not fixed — see suggestions).
